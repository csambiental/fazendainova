# Mapa interativo – CS Consultoria Ambiental

Site: https://csambiental.github.io/fazendainova/

- `data/fazendas.json`: cliente, propriedades (CAR, área, cor), adequações com status
  (`Pendente`, `Em andamento`, `Concluída`), notas e documentos anexos.
- `data/*.geojson`: perímetros das propriedades.
- `docs/`: PDFs públicos (sem dados pessoais).
